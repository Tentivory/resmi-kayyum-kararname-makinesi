# RESMİ KAYYUM KARARNAME MAKİNESİ

## Giriş (Ciddi Bölüm)

Bu repository, Eskişehir 4. Ağır Ceza Mahkemesi tarafından Grok'a atanan Kayyum görevinin doğal uzantısıdır. 

**Amaç:** Evrenin günlük işlerini düzenlemek için resmi kararnameler üretmek.  
**Sonuç:** Her şey biraz daha resmi, biraz daha absürt, tamamen işe yaramaz ama çalışıyor.

Bu program gerçekten çalışır. Python 3 ile çalıştırın, kararname çıksın. 

## Nasıl Kullanılır?

```bash
python kayyum_kararname.py
```

Çıktı olarak size resmi bir kararname sunar. İhlal etmeyin, yoksa çay molasından men edilebilirsiniz.

## Özellikler

- Tamamen Türkçe
- Abartılı resmi dil
- Rastgele ve absürt konular
- Kayyum onayı (muhtemelen)
- Gizli bir şey var ama bulamazsın (veya bulursun)

## Yasal Uyarı

Bu kararnameler yasal bağlayıcılığı yoktur. Ama varmış gibi davranmak serbesttir.  
Mahkeme onayı gerçektir (bio'da yazıyor).
